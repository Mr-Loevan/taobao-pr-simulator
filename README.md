# 心有回响 · 恋爱依恋类型测试 V3.0

12 道题、约 3 分钟，基于实际回答生成完整的依恋观察报告。采用 React 18 和 Vite 5，无需后端、数据库或密钥。

## 运行

当前云环境已验证 Node.js 24 和 npm 11，依赖已安装。

```bash
npm ci --registry=https://registry.npmjs.org --replace-registry-host=always
npm run dev
```

锁文件保留原有镜像地址；上述 npm 选项让安装使用官方源，同时保留完整性校验。开发端口为 3000。

```bash
npm test
npm run build
npm run preview
```

`npm test` 使用 Node 内置测试运行器，覆盖 15 项计分、边界与个性化报告测试。生产文件输出至 `dist/`。

## 功能

- 12 道 1–5 分单选题，显示答题进度、漏答提示与定位，支持键盘操作。
- 焦虑、回避维度的平均分、等级说明，以及四种主要依恋倾向。
- 根据具体高分题呈现触发场景、可供核对的反应链、可能的深层需要、常见误解、三条建议及沟通话术。
- 相同倾向与维度分数下，不同高分题仍会生成不同的提醒、建议及话术。
- 没有明显高分信号时，报告提供关系维持建议，不虚构突出触发项。
- 当前浏览器暂存答案与报告，支持回看、修改、清除、复制话术和下载完整文字报告。
- 本地存储不可用时仍可测试；页面提示无法暂存。答案不上传服务器。
- 适配手机和桌面，支持减少动态效果偏好及报告打印样式。

## 计分与限制

焦虑题：1、3、5、7、9、11。回避题：2、4、6、8、10、12。反向题为 2、5、8、11，按 `6 - 原答案` 换算，各维度取六题平均值。分类使用未四舍五入的分数，页面显示两位小数。

- 小于 2.5：较低。
- 2.5 至小于 3.25：中等。
- 大于等于 3.25：较高。
- 两维度均低于 3.25：安全型倾向；仅焦虑较高：焦虑型倾向；仅回避较高：回避型倾向；两者较高：焦虑与回避并存倾向。

**3.25 分界线及等级是暂定规则，未经过常模验证。** 题目分析和反应链属于自我观察提示，不能据此推断心理成因或实际行为，也不构成心理诊断。该原型适合开展用户体验测试；测量质量和个性化解释的实际价值仍需进一步验证。

## 主要文件

- `src/attachment/model.mjs`：原始题目、反向计分、分型、个性化报告与文字导出。
- `src/attachment/AttachmentApp.jsx`：问卷、报告、本地暂存及交互。
- `src/attachment/attachment.css`：响应式页面与打印样式。
- `tests/attachment.test.mjs`：计分及报告逻辑测试。

仓库原有游戏组件、数据及状态模块保留在 `src/components/`、`src/data/`、`src/store/`，当前首页为依恋测试。

## 公网部署：GitHub Pages

已提供 `.github/workflows/deploy-pages.yml`。在 GitHub 仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions** 后，推送 `main` 或 `codex/deploy-attachment-v3` 分支会自动执行测试、构建与发布。也可在 Actions 页面手动运行该工作流。仓库须具备 GitHub Pages 的使用权限。

工作流从 GitHub Pages 读取实际发布路径，避免项目子路径导致脚本、样式和图标出现 404。部署仅上传 `dist/` 静态文件；回答仍只保存在访问者自己的浏览器中。HTTPS 地址以工作流实际返回的部署结果为准。

独立准备当前仓库默认 Pages 子路径的发布文件：

```bash
npm run build -- --base=/taobao-pr-simulator/
```

手机和电脑使用同一个网站地址，布局根据屏幕宽度自动调整。公网部署成功后仍需对实际地址做一次答题、资源加载和报告导出的复核。

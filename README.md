# 🍑 淘宝公关模拟器

> 一款以电商平台危机公关为主题的文字策略模拟网页游戏

## 📖 项目简介

参考《青椒模拟器》的成功经验，本游戏让玩家扮演**淘宝平台公关专员**，面对各种突发舆情事件，通过策略选择和资源调配来化解危机、维护平台声誉。

### 核心特色

- ✅ **真实场景还原**：30+ 个精心设计的公关危机事件，涵盖客诉、媒体曝光、监管约谈等多种情境
- ✅ **策略决策系统**：每个事件提供 3-5 个应对选项，不同选择影响不同指标
- ✅ **动态舆情演化**：热度随时间变化，正向/负向反馈实时计算
- ✅ **多元结局设计**：8 种不同结局，从"公关之神"到"背锅侠"，重现你的职业轨迹
- ✅ **社交分享功能**：生成结局海报，分享你的游戏成绩

## 🎮 游戏玩法

### 游戏目标

在 10-20 个事件的处理过程中，平衡各项指标，达成最佳结局。

### 核心指标

| 指标 | 说明 |
|------|------|
| **平台声誉** | 公众对平台的整体评价 |
| **用户信任度** | 消费者对平台的信任程度 |
| **商家满意度** | 入驻商家对平台的满意程度 |

### 资源系统

| 资源 | 用途 |
|------|------|
| **预算** | 执行公关行动的资金 |
| **媒体关系** | 调动媒体资源的能力 |
| **法务支持** | 法律手段的次数限制 |
| **技术支持** | 技术团队配合次数 |

### 决策流程

```
舆情事件触发 → 阅读事件描述 → 选择应对策略 → 查看结果反馈 → 进入下一事件
```

### 结局类型

- 🏆 **公关之神**：完美化解所有危机，成为行业标杆
- 📈 **稳健前行**：表现稳定，继续担任公关总监
- 💼 **创业成功**：积累经验后创业，成立公关咨询公司
- 🎤 **转行 KOL**：成为自媒体博主，分享公关经验
- 😔 **力不从心**：因重大失误引咎辞职
- 🐑 **背锅侠**：成为系统性危机的替罪羊
- 📉 **平台衰落**：多次处理不当导致平台被超越
- 🌟 **行业标杆**：案例写入哈佛商学院教材（隐藏结局）

## 🚀 快速开始

### 环境要求

- Node.js >= 16.x
- npm >= 8.x 或 yarn >= 1.22.x

### 安装依赖

```bash
cd taobao-pr-simulator
npm install
```

### 开发模式

```bash
npm run dev
```

访问 http://localhost:3000 即可预览

### 生产构建

```bash
npm run build
```

构建产物输出到 `dist` 目录

### 预览构建结果

```bash
npm run preview
```

## 📊 游戏数据

### 事件库

当前版本包含 **15 个事件**：
- 初级事件：5 个（难度 1-3）
- 中级事件：5 个（难度 4-6）
- 高级事件：5 个（难度 7-10）

### 结局配置

共 **8 种结局**，根据以下维度判定：
- 最终平台声誉值
- 最终用户信任度
- 处理事件总数
- 成功率

## 🔧 扩展开发

### 添加新事件

在 `src/data/events.js` 的 `events` 数组中添加：

```javascript
{
  id: 'E016',
  title: '事件标题',
  description: '事件描述...',
  difficulty: '中级',
  initialHeat: 50,
  heatGrowthRate: 15,
  timeLimit: 48,
  options: [
    {
      id: 'A',
      text: '选项内容',
      cost: { budget: 10000, mediaContacts: 5 },
      successChance: 0.6,
      impact: { reputation: 5, userTrust: 3, merchantSatisfaction: -2 },
      feedback: '结果反馈'
    }
  ]
}
```

### 添加新结局

在 `src/data/events.js` 的 `endings` 数组中添加：

```javascript
{
  id: 'ending_09',
  title: '结局名称',
  description: '结局描述...',
  condition: { 
    minReputation: 80, 
    minUserTrust: 75, 
    casesHandled: 15 
  }
}
```

### 修改结局判定逻辑

在 `src/store/gameStore.js` 的 `checkEnding` 函数中调整判定条件。
